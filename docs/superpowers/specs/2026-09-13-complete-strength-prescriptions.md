# Complete strength preview policy

This extends goal-linked exercise blocks into four-pattern session previews. It does not activate a new live plan, prescribe progression, or provide medical clearance.

## Evidence and interpretation

ACSM's 2026 position stand supports resistance training across major muscle groups and does not require training to failure for general benefit: https://acsm.org/resistance-training-guidelines-update-2026/

CDC describes muscle-strengthening work across major muscle groups, with one set useful and additional sets potentially beneficial: https://www.cdc.gov/physical-activity-basics/adding-adults/what-counts.html

The precise time allowances, 6-8 rep previews, 2-3 reps-in-reserve cue, 28-day evidence window, and set-reduction order below are conservative product heuristics, not validated personalized training equations.

## Construction

- Place the supported goal movement first. Add the missing push, pull, squat, and hinge patterns using the existing template approach.
- Full-gym/loaded complements: floor press, one-arm row, goblet squat, Romanian deadlift. Bodyweight complements: wall push-up, prone W raise, squat, glute bridge. A prone W raise is introductory upper-back work, not equivalent to loaded pulling or pull-up progression.
- A dumbbell-only profile does not prove access to a bench. Unsupported variants and equipment conflicts return explicit blockers.
- Reserve 5 minutes warm-up, 3 cooldown, 2 setup per movement, 1 minute per working set (2 minutes for a bilateral completion of unilateral rows), and 90 seconds between sets. These are planning allowances, not instructions to rush repetitions.
- Start with up to two sets per movement. Reduce complementary sets first, then the goal set count if necessary. Keep at least one set for every pattern. If the complete minimum cannot fit, request more available time instead of deleting a pattern.
- Reuse the anchor's already-validated working load. Complement loads require the exact exercise and convention, a recent matching set of at least 8 reps, and explicit RIR of at least 2. A harder latest set invalidates reuse of an older easier set. Conflicting simultaneous records require calibration.
- Never use target weights as working loads, infer per-hand values from total load, or transfer load between exercise variants. Unknown working levels use comfortable-load or easier-variation calibration guidance.

## Remaining limits

These previews do not evaluate injuries, full recovery between days, complete weekly muscle coverage, or progressive overload. Goal-specific deadline feasibility is not established. The app must keep those limits visible until the corresponding policies are implemented and evaluated.
